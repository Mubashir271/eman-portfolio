# Eman Mughal Portfolio

Project-based portfolio of Eman Mughal, graphic designer (branding, packaging, illustration). Each project has its own full page and colour theme.

Open `index.html` in a browser, or serve the folder with any static host.

Projects so far: Qissa-e-Urdu Café, PINDIMOB, Sugar Munch, Pehchaan Clinic, SpinX, Autism, Typography, Layouts.
